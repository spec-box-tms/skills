# Accessible Interaction Requirements

Use this checklist when a feature has keyboard interaction, focus movement, or
meaningful dynamic changes that must be communicated to users.

## Establish

Determine keyboard operations for the available function, initial focus and
focus movement, focus return after a contextual interaction, and which dynamic
changes need an observable announcement. Ask only where the requirement,
existing behavior, or applicable interaction makes the information necessary.
Do not prescribe visual styling or implementation technology.

## Quality criteria

Keyboard requirements identify the operation and resulting action or context.
Focus requirements identify the starting condition, destination, and trigger.
State-announcement requirements identify the change that users must receive and
the meaningful information it conveys.

## Standard groups

- `Keyboard control` for keyboard operations.
- `Focus` for focus placement, movement, and return.
- `State announcements` for meaningful dynamic changes.
